# PostgreSQL Walkthrough

In this repository I am going to work through the PostgreSQL documentation, not exhausively, but looking into database design and querying using three databases that hold flight data, taxi data, and artificial e-commerce data respectively. I will focus on chapters two (SQL language) and three (server administration). I decided to do this to refresh my memory with using PostgreSQL and also because I remember back in 2006 thinking the documentation for the project was the best documentation I had ever read, and I wonder if that still held.

* Part [zero](Part-zero-setting-up.md) is where I create the databases, and for the taxi data perform some QA and transformations to get it into a state for use in this project.
